02

Conhecendo o <html> e o <head>

<html lang="pt-BR">

    <head>
        <meta charset="UTF-8">
        <title>Minha página</title>
    </head>

</html>

lang="pt-BR"

O atributo lang informa o idioma principal do documento.

<head>

O head guarda informações e configurações importantes da página. Ele não é o lugar onde normalmente colocamos o conteúdo principal que o visitante lê.

<meta charset="UTF-8">

O navegador precisa saber como interpretar os caracteres. O UTF-8 permite trabalhar corretamente com acentos e muitos outros caracteres.

04

Organizando a página: <div>, class e id

Uma div pode ser pensada como uma caixa usada para agrupar e organizar conteúdo. 

<div class="caixa">
    <h2>Meu conteúdo</h2>
    <p>Um texto dentro da caixa.</p>
</div>

O atributo class dá um nome que pode ser utilizado por vários elementos. 

<div class="caixa">Caixa 1</div>
<div class="caixa">Caixa 2</div>
<div class="caixa">Caixa 3</div>

Já o id identifica um elemento específico. 

<div id="principal">
    Conteúdo principal
</div>

09

JavaScript: fazendo a página reagir

HTML cria elementos. CSS controla a aparência. JavaScript pode fazer a página reagir às ações do usuário. 

const botao = document.querySelector("#meuBotao");

botao.addEventListener("click", function () {
    alert("Você clicou!");
});

🧪 Clique no botão

Você ainda não clicou.

Observe: o HTML criou o botão, o CSS pode mudar sua aparência e o JavaScript está observando o clique.

🧪 Projeto final: seu primeiro arquivo de texto

Agora vamos juntar os conceitos. Escreva um pequeno texto e envie para o servidor.

O arquivo ainda não foi enviado.

O que acontece?

  1. Você escreve no navegador.
  2. O JavaScript coleta o conteúdo.
  3. Uma requisição é enviada ao servidor.
  4. O servidor recebe os dados.
  5. O servidor pode salvar o arquivo.
Importante: em hospedagens como Render, o armazenamento local do servidor pode ser temporário. Se você quiser que os arquivos permaneçam no repositório Git, o servidor deverá usar uma integração com GitHub/GitLab ou outro armazenamento persistente.
