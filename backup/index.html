01

Estrutura Básica: DOCTYPE, HTML e HEAD

Toda página web precisa de uma estrutura fundamental que fica invisível para o visitante, mas é essencial para o navegador.

<!DOCTYPE html>

Esta linha informa ao navegador que estamos trabalhando com um documento HTML5 padrão. Em seguida, temos o <html> e o <head>. 

<html lang="pt-BR">

    <head>
        <meta charset="UTF-8">
        <title>Minha página</title>
    </head>

</html>

Entendendo o <head>

O head guarda informações e configurações importantes da página. Ele não é o lugar onde colocamos o conteúdo visual, mas sim os metadados.

  • UTF-8: A tag <meta charset="UTF-8"> permite trabalhar corretamente com acentos e caracteres especiais.
  • Title: A tag <title> é o que aparece na aba ou janela do navegador.

03

Organizando a página: <div>, class e id

Uma div pode ser pensada como uma caixa usada para agrupar e organizar conteúdo. 

<div class="caixa">
    <h2>Meu conteúdo</h2>
    <p>Um texto dentro da caixa.</p>
</div>

O atributo class dá um nome que pode ser utilizado por vários elementos.
